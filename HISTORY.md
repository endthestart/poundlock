# History

Poundlock was developed in a private repository from September 2026 by Michael
Anderson. This public repository starts at 0.3.0 with a single commit of that
work; private deployment configuration and test captures were left out.
Development continues here.

Earlier internal names survive in a few migrations that existing installations
still need: `RCHARM_*` environment variables are refused with a pointer to their
`POUNDLOCK_*` replacements, and an `rcharm.sqlite3` database is renamed on start.
